# Web Portfolio

A static portfolio built with React, TypeScript, and Vite. Portfolio content is stored in `data/content.json`; contact is handled through direct email, phone, and social links.

No database, admin application, or environment variables are required.

## Commands

```sh
npm install
npm run dev
npm run lint
npm run build
npm run preview
```

The development server runs at `http://localhost:5173`. Production files are generated in `dist/`.
